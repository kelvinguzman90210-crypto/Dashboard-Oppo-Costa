# OPPO Costa - Dashboard de ventas y activaciones

Dashboard estático para procesar localmente el reporte Excel `Report_By_Imei_IR...xlsx`.

## Uso
1. Abrir la página.
2. Arrastrar el Excel diario.
3. Revisar ventas, activaciones, pendientes, promotores, modelos e IMEI.

## Privacidad
El Excel se procesa en el navegador. No se envía a un servidor.

## GitHub Pages
Publicar el contenido de este repositorio desde la rama principal (`main`) y la carpeta raíz (`/`).
